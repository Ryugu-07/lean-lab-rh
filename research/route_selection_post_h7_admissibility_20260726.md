## Selection rule

Historical-route work is an omission search. A family is not exhausted when one local endpoint
closes. The selector asks which surviving source mechanism is nearest to a decisive inference,
which source step has not yet been reconstructed, and whether the missing step can expose an
overlooked strengthening or a precise obstruction. Original conjectures, falsification, and
direct attacks remain open, but omission-seeking coverage is the default main line while major
historical mechanisms remain unaudited.

Local API familiarity is not a selection reason. Numerical-bound optimization remains parked
unless it becomes an input to an RH-bearing mechanism.
